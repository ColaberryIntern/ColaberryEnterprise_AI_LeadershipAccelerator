02Prompt stages

  • Generation — ARCHITECT_MINDSET_GENERATION_PROMPT (in the authored entry), written against the injected WEEK CONTEXT, emits the structured AmScenario JSON for Weeks 1-12. Week 0 ships a hand-authored scenario in code (data/architectMindsetScenario.ts), because Week 0 is the null-blueprint free-preview tier.
  • Evaluation — a graceful debrief prompt in architectMindsetService.evaluate() that produces a two-sentence, no-jargon, no-single-correct-answer observation, with a deterministic fallback (assessBaseline) so completion is never blocked by an AI outage. Week 0 is a baseline (unscored).
  • Reflection / design / renderer / improvement / github stages: documented in 17-prompt-pipeline intent; not required for Week 0 (github off; reflection is the Architect Interview, driven by the authored scenario).

The prompt/scenario version is stored on each experience (student_progress.scenario_version).

06Cost estimate

Per completed Week 0 experience: one optional AI evaluation call (gpt-4o-mini, ~400 output tokens, roughly $0.0003), and it is skippable — the deterministic fallback produces the baseline observation at zero cost if the model is unavailable. Week 0 does no content generation (the scenario is hand-authored in code). Thumbnail: a one-time ~$0.06 gpt-image-2 render when the photographic banner replaces the current vector-derived JPG.

07Completion & accessibility verification

Completion (backend-authoritative)

  • All 14 gates enforced server-side in complete() before delegating to the platform's onCardCompleted (unit-tested).
  • Idempotent: unique (card_id, enrollment_id) + findOrCreate; completed record immutable; re-complete returns the stored ADR with no re-award.
  • Custom-answer-empty rejected at the API (422 custom_answer_required).
  • Graceful evaluation failure: deterministic fallback, work preserved, safe retry.

Accessibility (built-in)

  • Radiogroup semantics on options; visible focus rings; keyboard operable.
  • Required state announced by text + banner (role="alert") + invalid outline, never color alone.
  • prefers-reduced-motion disables the tunnel/blueprint drift.
  • Charts carry role="img" + descriptive labels; time dial has a text label.
  • Light + dark via --am-* tokens under both .tl-de and .rt scopes.

08Known limitations

  • Live E2E pending a dev deploy (§05). The strongest feasible local verification (unit + tsc + contract) is done; the running-instance demonstration is the recommended next step and needs a shared-infra dev deploy I am confirming first.
  • Thumbnail is vector-derived (on-brand SVG → JPG via sharp, matching the approved art direction). The photographic gpt-image-2 banner can replace it any time — the scene prompt is registered in scripts/curriculum-type-thumbnails/prompts.json.
  • Pre-existing, not mine: the community_live_session XP test failure (§04) and the uninstalled-dep tsc errors in untouched files (both present on main).
  • Mindset Ledger is derived (aggregated on read). A materialized cache is a later option only if query cost demands it.
