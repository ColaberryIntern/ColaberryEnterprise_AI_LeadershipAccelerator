What an intern sees, from signing in to granting their agent a tool

Five stages, using Sarbjit and Marketing as the worked example. Two things this is designed to make unmissable: an intern controls their section and their agent separately, and a tool only reaches the agent through an approval the intern cannot give themselves.

5

Granting a tool — the step she cannot do alone

Four moves. She makes the first and the last; she cannot make the middle two.
Sarbjit
Proves it by hand, then proposes it as a tool
Manager
Confirms the capability is real
You
Approve the grant
Agent
Can now do that one thing
Four rules the system enforces, not conventions. The proposer can never approve their own grant · a tool cannot be granted for a capability still in draft · a grant writes the tool and nothing else, so it can never quietly raise autonomy · an automated identity can never stand in for the human approval, however it is labelled.
