What the sweep found

Defect · fixed in this change

The page told students to publish their recording publicly, next to a button that made that unnecessary

PREP-2's step 4 reads "Upload the file to Google Drive or OneDrive and set sharing to 'Anyone with the link can view', or upload it to YouTube as Unlisted." Directly beneath it sits Use a Studio recording, which takes a recording the platform already holds.

The guide copy was written when a link was the only way in. It kept saying so for a day after that stopped being true. A browser probe confirmed both strings on the same rendered page.

Fixed: the hand-in advice now leads with the Studio room and keeps uploading as the fallback for recordings made elsewhere.

Defect · fixed in this change

A recording task opened on "Paste a link", with the workaround in the loud button

Visible in the mobile shot below: Paste a link carries the selected-state treatment and Use a Studio recording is the quiet one. The form opened on the old path, so the styling advertised it.

Fixed: PREP-2 and PREP-5 now open on the picker. A student who recorded elsewhere is one click from the URL box, and the picker's empty state says so.

Suspected · disproved

The "clipped" mobile card was a capture artifact, not a layout bug

The first capture run sliced the instructions mid-sentence at 390px, which looked like a serious mobile defect. It was not. The workspace puts its main column in overflow-y: auto, and a fullPage screenshot captures the box rather than the content.

Measured in the browser rather than argued about: main.rt-mid reports clientHeight 351 → scrollHeight 1990 with overflow-y: auto — it scrolls, and a real user reads all of it. The capture script now expands inner scrollers before shooting, which is why the images below are complete.

What held up

  • No horizontal scroll at 390. The six-stage grid reflows to 3×2 and stays legible.
  • Focus states exist already. presentationStudio.css carries :focus-visible on every button and link, plus prefers-reduced-motion and a dark-mode block scoped twice because the theme attribute lands on two elements.
  • The stage switcher is keyboard-operable. TemplateChooser is a real role="radiogroup" of real buttons with aria-checked.
  • Colour is never the only channel. Checked and cleared — the red warnings carry their meaning in words.
  • PREP-6 shows no form at either width.
