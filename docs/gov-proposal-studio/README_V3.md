# Proposal Studio v3: handoff

**How to use**
1. Unzip at the repo root. Files land in `docs/gov-proposal-studio/`, next to the existing package.
2. In Claude Code, from the repo root, say: `Read docs/gov-proposal-studio/STUDIO_V3_PROMPT.md and start with V1.`

**Contents**

| File | What it is |
|---|---|
| `STUDIO_V3_PROMPT.md` | The build instructions, in five phases (V1–V5). |
| `designs/proposal-studio-v3.html` | The approved clickable demo. Open it in a browser; no server needed. |

The demo uses sample data on the Saratoga Springs contract. Its scores, references and quotes are illustrative, not facts.

**The model in one line:** the AI builds and judges every document; every scan lists exactly what it needs from a person; the person supplies those inputs and gives one Go at Gold.
