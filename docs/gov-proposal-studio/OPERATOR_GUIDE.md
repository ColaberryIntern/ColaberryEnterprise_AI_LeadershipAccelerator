# Gov Proposal Studio — Operator Guide (v3)

For the person driving a bid in the Studio (admin) and the intern on an edit share. Plain
steps, no code. The model: the agent builds and judges; you answer what only a person can,
then give one Go.

## Start a proposal

1. Open the contract's Studio. The **Where we are** view shows readiness, the pursuit stage,
   and the ranked next moves.
2. Confirm the **Blueprint** (the cited rulebook from the solicitation ZIP). A rule with no
   real quote was dropped, never invented.
3. Press **Build all documents** (Where we are, or Document set). The agent drafts, checks and
   revises every document that has not been started. Watch the agent panel's state move through
   Building → Judging → Revising.

## Answer what needs you

- The **Needs you** list (left rail, and the "Needs you N" chip in the header) is everything a
  person must supply: a fact, a decision, a file, a signature, a setting (like the demo URL).
- Answer one inline. The moment you do, the agent **picks that document back up automatically**.
- Interns never see pricing or the Gold decision — those stay with an admin.

## Edit a document yourself

- Open a document → **Draft & versions** → **Edit**. Save writes a new version, re-runs the
  checks, and hands it back to the agent only if it is still below the bar. If your edit passes,
  the agent leaves it alone.
- The **Outline** tab shows each section's page budget, the requirements it covers, and whether
  it is drafted yet.

## Review and approve

- **Review gates** shows every document across the six checks. Pink, Red and White glove light
  up on their own as the AI judge passes them — there is nothing to approve there.
- **Gold is the one human decision.** When every document passes, the **Go / No-go** panel
  turns on. Give the package a **Go** to approve it for submission, or a **No-go** with a note to
  send it back. You cannot approve a version you last edited yourself (separation of duties).

## Package and submit

- Once everything passes and Gold is a Go, **Package & submit** assembles the PDFs, the sealed
  price file (admin only), the compliance matrix and a manifest.
- Exporting is **not** submitting — you upload to the agency's portal and record the receipt.

## If something is wrong

- Use **Report a problem** (bottom-right in the Studio). It emails the Gov Studio inbox with the
  route, the errors and a screenshot, so it gets picked up and fixed.

## What the agent will never do

- Invent a client, a metric, a date, a dollar figure, a certification or a person. A missing
  fact becomes a `[PLACEHOLDER]` and a need, never a guess.
- Approve its own work. Every gate that ships is a person's Go at Gold.
- Show pricing or identities to an intern.
