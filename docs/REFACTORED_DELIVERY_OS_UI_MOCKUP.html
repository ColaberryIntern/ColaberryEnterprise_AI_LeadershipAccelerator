What the builder half is proving

  • Same project truth as the client sees, with more support — Learn mode changes the help, never the data or the permissions.
  • Failures are shown as distinct kinds: stale evidence, not-run evidence and unscored trust dimensions are three different problems.
  • Deploy is visibly disabled, because readiness and authorization are separate questions.

Before this gets built — what I need from you

  • Layout: left rail + top bar, or top tabs only? The rail suits eight destinations; tabs suit a narrower client surface.
  • Density: this is calm/executive. Do you want it tighter and more Bloomberg-like?
  • Client tone: the client screens explain themselves in plain language. Keep, or strip to bare data?
  • Scope: both halves at once, or client room first so it can be deployed and looked at sooner?

Nothing is built yet. On approval I will implement these as React pages against the existing route conventions, and they will still need deploying to a dev instance and looking at — green CI is not visual verification.
