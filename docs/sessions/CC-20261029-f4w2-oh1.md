      - Dry run by default. It never activates and never sends.

      - It creates Maya's sender profile ("Maya at Colaberry" <maya@colaberry.com>), the 3-email sequence (T-2 days, T-1 day, T-1 hour) and the campaign as a draft, submitted for approval.
