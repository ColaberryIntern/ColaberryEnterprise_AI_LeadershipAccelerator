## Failure model (Failure-First)

- **Upstream unreachable:** existing capped retry (3 attempts, exponential backoff, 20s timeout); that brand fails, the others still sync, the job exits non-zero.
- **Bad registry edit:** a target outside `apps/*/src/assets/design` or the exact allowlist is refused at runtime before any write.
- **Upstream reintroduces an external import:** stripped deterministically; the guard test catches a hand edit.
- **Someone re-adds a platform token inside the vendored files:** the next sync reverts it and the PR shows it; `platformTokens.test.ts` pins where they live.
- **Not handled:** the nightly PR is opened with `GITHUB_TOKEN`, which does not trigger CI on that PR, and the workflow builds only `apps/*`, not the CRA frontend. A token change to the app copy is therefore reviewed by eye, not by CI, until someone pushes to the branch. Logged, not fixed here (scope).
