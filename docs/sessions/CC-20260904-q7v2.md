- [x] Add a weighted word cloud and free-text search to the records index
  - Date: 2026-09-04

  - What changed: Ali: "we scoped out a word chart to make it easier to filter the list of Case studies. Can we do that and/or the left side filter system. Also allow for typed text with instance filtering." The left sidebar already existed (six facet groups, URL-addressable); the cloud and the search did not. **The cloud is a rendering of the existing facets, not a second filter system** - every word is a facet the sidebar also lists, and clicking one calls the same toggle a checkbox does, writing the same URL parameter, so the two cannot disagree. **Search is server-side** (`?q=`), matched against the projected card text, debounced 250ms in the input and committed to the URL so a filtered view stays shareable. Facet labels are now humanised for display (`governed-ai-remediation` -> `Governed AI remediation`), in a shared module so the sidebar and cloud print the same words.
  - Verification: Both stacks `tsc --noEmit` exit 0. 20 new backend tests for search; 14 new frontend tests for the cloud and the humaniser; the five index suites stay green. Verified in a browser: 16 cloud terms render, clicking one writes `?stack=typescript` and marks the chip `aria-pressed`, typing debounces into `&q=audit+trail`, and the two compose.
  - Notes: **Search had to be server-side and the reason is a correctness one, not a preference.** The list is paginated at `limit=12`, so a client-side filter would only ever see the records already on screen - a reader on page 1 would be told there is no match for something sitting on page 2. **It also had to search the PROJECTION rather than the snapshot, and that is a privacy property.** Consent decides whether a record's organization is a real name, a descriptor, or nothing; searching raw snapshot text would let anyone confirm a name consent had replaced, by typing it and watching the record appear. A test asserts that an anonymised record is unreachable by the name its descriptor replaced. **Two extractions were forced by ceilings rather than chosen:** `StoriesFilterAside` (the page passed its 400-line contract) and `facetLabels.ts` (the model passed its 300-line one). **Honest at current scale:** with two published records almost every term weighs 1, so the smallest cloud tier is deliberately kept readable rather than shrinking rare terms away - a young library is mostly rare terms.
