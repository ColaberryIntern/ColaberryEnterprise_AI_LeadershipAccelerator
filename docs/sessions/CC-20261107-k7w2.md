Agreement" (`a563218c`) was materialized on 2026-11-05 16:10 UTC under his enrollment with

`materializeGovBuildProject` is supposed to write that row (`ensureAssigneeCanBuild`, commit

the Nov 5 image nor its logs survive. Two candidates remain — prod was on a pre-10-27
image, or the insert threw and was swallowed. The second was possible, which is the defect
fixed below; the first is unfalsifiable now.

### Correction to the blast-radius claim above

The claim that eight delivery projects carried a materialized build with zero membership rows was wrong,
and measuring it properly moved the number in both directions. The original query only proved "no
membership row"; a build was inferred from that without checking. Measured: those seven carry **no build
at all** - no `contract_tracks.solution_student_project_id`, no student project, no intern. They are
pursuits approved into a delivery project where "Create the monitored project" was never run, so nobody
was waiting on any of them.

The same query also **under-counted** a different case. A membership that exists but is `revoked` hides a
build from its builder exactly as a missing row does, because the nav counts only active rows, but
`NOT EXISTS` over all rows skips those projects. There are four.

Real picture: seven delivery projects have a materialized build. Three are healthy (Obi/Crash,
Akiwam/RFP Enterprise Work Order Management, Omolola/2026 Saratoga Springs) and four are blocked by
revoked membership. **So the uuid bug had exactly one victim: Crash.** That does not change the fix - the
production log line proves the bug, and every future press of that button would have failed the same way.
It changes only the claim about damage already done. Corrected on PR #3753 and on the Basecamp ticket at
the time; this entry had kept the wrong figure, and the code comment in `govBuildAssignment.ts` that
repeated it is corrected in the same commit as the handoff tooling below.

Ali confirmed on 2026-11-08 that the revocations were deliberate testing, and that the intended state is
one project each for Obi, Akiwam and Omolola. That state is met.
