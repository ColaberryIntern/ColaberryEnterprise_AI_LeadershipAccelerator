- [x] **`proposalExtractor` joined soft-wrapped lines so a requirement that wraps across two lines stays one sentence (the Herriman symptom), and a new `govRequirementItems` module groups each extracted obligation into one of four categories (submit / rule / scope / after_award) with its source citation, surfaced from the extract route.**
