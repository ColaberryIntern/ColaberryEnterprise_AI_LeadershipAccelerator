  - Notes: `STAGE_PERMISSION` maps onto the **existing** `DeliveryPermission` union in `modules/delivery/deliveryRoles.ts` — all 13 values verified present before use, and the map is typed so a typo is a compile error rather than a check that can never pass. It uses the *specific* grant per stage (`requirement.approve`, `architecture.approve`, `agent.approve`, `design.approve`, `contract.approve`, `story.write`/`review`/`execute`, `release.approve`/`deploy`) rather than one blanket `project.manage_authority`, so a design reviewer cannot implicitly approve a release. Submitting *for* approval is `project.write`, not an approve-class grant — asserted, because conflating the two is how a gate gets bypassed by the person who built the thing.
  - Notes: Pure and non-throwing. A malformed stored stage is a refusal with a reason rather than an exception, so a value that has drifted cannot crash a read path.
