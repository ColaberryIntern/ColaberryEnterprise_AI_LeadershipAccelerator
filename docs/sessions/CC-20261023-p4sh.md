## Why the queue mattered

A learner switching a take to Public created a showcase with `published_at` NULL
and saw "Waiting for staff approval — still private". Nothing listed what was
waiting. The approve endpoint had existed since the lifecycle shipped; the queue
service since 18 October. Neither had a screen, so the only way to find a request
was to query the database by hand — which is how both demos live in production
today were approved. The next learner to use the share button would have waited
indefinitely.

## Open, for Ali

Social sharing is **download the file and post it yourself**, with the platform
composers opening with a caption prefilled. One-click sharing needs a genuinely
public, no-login page for a published demo — a decision about who can see a
student's face on the open internet, not an implementation detail.
