## Open, for Ali

Social sharing is implemented as **download the file and post it yourself**, with
the platform composers opening with a caption prefilled. It is not a one-click
share, because every recording sits behind a signed, audience-checked URL and the
gallery needs a login — a LinkedIn post linking either address shows a sign-in page
to everyone who clicks it.

A genuinely public, no-login page for a published demo would make one-click sharing
real. That is a change to who can see a student's face on the open internet, which
is a governance decision rather than an implementation one.
