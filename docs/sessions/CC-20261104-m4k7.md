  - What changed: added `directives/run-monthly-enrollment-batches.md` - the model decided by
    Ali with Taiwo on 2026-11-05 (self-paced enrollment in monthly batches; you join the batch
    of the month you pay in; Jackie runs a WhatsApp group per batch; orientation is the first
    Monday of the following month, batch-only the first time and combined after that), plus the

  - Verification: documentation only, no code paths touched. The two conventions in it were
    checked against the code they constrain - `start_date` holding the orientation date rather
    than the first of the batch month is required by `cohortUrgencyService` (renders
    `Starts in ${daysUntilStart} days`), `schedulerService` (cancels payment reminders once
    `cohort_start_date` has passed), `sequenceService` (schedules the readiness ladder relative
    to `start_date`), `cohortRoutes`/`contextGraphService` (both select
    `WHERE start_date > NOW()` for "next cohort") and `SessionControlTab` (filters
    `start_date >= today`); the one-open-batch-at-a-time convention is required by
    `getNextCohort()`, which orders open cohorts by `start_date ASC` with no date filter.
  - Notes: the model has no code behind it yet. Placement is still manual - every paid write
    path takes `cohort_id` from its caller (`enrollmentService.ts`) and the payment webhook only
    flips `payment_status`, so nothing computes "the batch for this month". Two gaps are called
    out in the directive rather than left to be discovered: a newly created batch has no
    `curriculum_modules` rows and `curriculumService` throws
    `No curriculum modules found for cohort <id>`, and `selectNextOpenCohort()` - which has no
    callers today - would place a mid-month signup in **next** month's batch if it were ever
    wired into placement.

   it has fired on **7 scheduled actions in the whole history** (10 ever carried a
   `cohort_start_date`; 7 cancelled, 3 sent), five of them the November readiness ladder stamped
   with a 2026-11-05 start. So the defect is real and narrow - it is **not** an explanation for
   the November batch's unpaid majority, and was not reported as one.
