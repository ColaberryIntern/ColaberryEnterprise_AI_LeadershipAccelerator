Deterministic + auditable (same inputs -> same verdict); no LLM. New dashboard `frontend/src/pages/admin/govWorkspace/BidDecisionDashboard.tsx`: band + headline, KPI cards (PWin, Expected Value, eligibility gaps hard/conditional, deadline/feasibility), the knockout screen with operator status controls, the PWin factor breakdown with 0-5 operator ratings + a new/recompete toggle + bid-cost/ROI, and a Mermaid decision-path reusing the app's existing `MermaidDiagram` (no new dependency). Replaces the old inline `deriveBidDecision` block in the Go/No-go step (import removed).   - Verification: engine jest test covers knockout classification, hard-fail -> no-bid + null economics, conditional -> bid-with-conditions, preliminary never auto-no-bids, recompete cap 70 / new-business cap 40, EV/PoA/ROI, the Mermaid highlight, and weights summing to 1.0.
