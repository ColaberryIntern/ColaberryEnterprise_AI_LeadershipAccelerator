## Why the webhook alone was not enough

The reported repo (`peacecrowne-oss/Saratoga-Springs-Municipal`) had exactly one webhook delivery —
a `ping` — because its only commit (the pairing "Connect this folder to Colaberry") predated webhook
registration, and GitHub does not backfill pushes. `last_push_at` was null, so "Pushes arriving"
stayed WAITING and the gov matcher never ran. The student's immediate fix is to push a new commit
(the webhook then catches it); this PR adds the Sync button as the documented fallback the SBP path
already had.
