## The root cause of "formatting is terrible"

**View D shipped with no stylesheet.** Twelve of the fourteen CSS classes it used had zero rules in
`adminInternship.css`: `aint-nudges`, `aint-brief`, `aint-table`, `aint-ok`, `aint-warn`,
`aint-alert`, `aint-muted`, `aint-promises`, `aint-warnings`, `aint-arm`, `aint-expand`,
`aint-note`. The page was rendering an unstyled HTML table at browser defaults.

The format was never "switched". Views A, B and C (Command Center, Triage Board, Activity Timeline)
are untouched and are the ones Ali liked; D is a fourth tab added on 10 Nov, and it never got the
styling the other three have.
