## What was built

A user-invocable skill that plans Ali's weekly live session: it picks the topic (curriculum + news
+ YouTube demand), writes and scores story angles, tightens the best one against the Idea rubric,
and writes a validated session blueprint with a `build-class-deck` handoff. It never asks a
question unless `interactive=true`.

| File | Role |
|---|---|

| `references/rubric.md` | Idea, Live (Room/Yield), Video and Sound-bite scorecards |
| `references/evidence.md` | Benchmarks; each marked with how well it is sourced |
