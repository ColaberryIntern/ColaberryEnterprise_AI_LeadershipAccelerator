The problem in one line: a metric arrived as the string `4 of 7`, with the seven
module names buried in a methodology paragraph. The card could not draw a meter,
because nothing in the payload said there was a denominator, and a reader could
see the number but not which four.

**Additive only.** Every new field is optional and every new gate rule is a no-op
on a metric with no `shape`. A record published before today loads, gates and
renders exactly as it did.
