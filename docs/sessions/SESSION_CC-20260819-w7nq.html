What changed**D2.** A student whose build published a gate-clean plan was shown the browser's starter template, permanently, chipped "⚠ starter template" over a tooltip saying it has no schedule and no Command Center. Root cause read from the code and reproduced: `claimBackendProject` calls `adoptServerIds`, which re-keys the placeholder's `id` **to the server UUID at claim time**, minutes before the plan exists. From that moment `reconcileProjects`' `matchIdx` matches, so the `supersede` branch — guarded by `matchIdx < 0 && mirrorIdx < 0` — is unreachable in exactly the case it was written for. **The brief's stated follow-on mechanism was inverted and the corrected one matters:** overlay was *not* a no-op. `generateSkeleton`'s template tasks carry **no `storyId` at all** (`id: '<localId>-t<n>'` and nothing else), so the template's keys and the plan's `STORY-NNN` keys are wholly **disjoint** — `adoptServerTasks` therefore **added** the plan to the template instead of replacing it.
