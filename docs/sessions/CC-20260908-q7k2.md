## Design decisions worth remembering

- **Violet, not coral.** The Claude Code spine (Setup Lab, Prompt Lab, Build Artifact(s) Lab) is coral `#D97757` with a "Claude Code" corner strip. Claude Studio is violet `#6C5CE7` with a "Claude.ai" strip. A student glancing at a week has to know which of the two tools an activity needs, and "Claude Code" on a card that never opens a terminal is the exact confusion this type exists to remove.
- **One format module, three consumers.** `claudeStudioFormat.ts` owns the `<style>` and the structure; the card seeder renders from it, the LLM generation prompt pins it verbatim, and the frontend parser reads its data attributes back. Same pattern as `intelCardFormats.ts`. Tests assert the contract from both ends, so a rename fails a build instead of silently degrading the card to raw HTML.
- **The body is self-contained.** If the bespoke renderer is ever unavailable the card still renders correctly through the generic `lessonDoc` iframe. The renderer is an enhancement, not a dependency, and the fallback is a visible downgrade rather than a blank card.
- **Completion is earned.** All four stages acknowledged, every reflection check confirmed, a well-formed Artifact link, and a written reflection — re-validated server-side. Exactly one `PortfolioArtifact` per `(enrollment, card)`; a resubmission revises it and completion runs through the idempotent `onCardCompleted` path, so revisions never award more points.
- **Honest verification state.** Submitted URLs are checked for format and obvious unsafety (https only, no embedded credentials, no loopback or private addresses) but **never fetched**. The record says `verification: 'unverified_link'` and `review_state: 'pending_review'`, and the UI says so in words. Nothing may upgrade that without a human review.
- **No private Claude data.** Conversations, prompts, and Project sources are never received, requested, or stored. `assertNoConversationDump` rejects a pasted transcript rather than quietly retaining it. Claude.ai is never embedded — launch controls are plain outbound links to the student's own authorized account.
- **The placeholder lint was wrong before it was right.** A first pass banned the bare word "placeholder", which failed Week 5, whose misconception list legitimately describes options analysis with decoy options. The check now matches authoring stubs (`tbd`, `lorem ipsum`, `todo:`, `placeholder text`, …) rather than vocabulary. A lint that forces prose to be worse is a bad lint.
