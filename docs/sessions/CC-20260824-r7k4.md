  - What changed: **`backend/src/data/weeks/week5.ts`** — the single `🔁 Week 3, callback` slide (“You already did this by hand”) is replaced by three slides that teach the tool-use round trip cold: `🧠 Start from zero` (the four steps, with the model choosing and YOUR program executing), `🔬 Watch it happen` (build and run one real round trip), and a reframed `📦 The big shift` that now pays off what the room just named instead of citing Week 3. **Every `kind: 'review'` block on Monday is gone** — the JSON-RPC wire format, the mismodelled `get_policy` server and its corrected resource version are now Claude Code prompts that produce the artifact, ask the student a question back, and wait. **Both terminal blocks became prompts too**: the toolchain check is now one prompt that detects the OS, checks Python/Node/uv, prints a PASS/FAIL table and installs what is missing (raw commands preserved in the rescue row), and the inspector launch is a prompt that runs it and narrates the panels. **The micro-build now belongs to the student**: the scaffold prompt built a hardcoded `support-kb` demo server, so the first server anyone ever built was somebody else's — it now opens with a `MY PROJECT:` parameter line carrying a named fallback for anyone without a project, and the two slides downstream stop naming `search_docs`. **`classTeachContent.ts` / `kitSpec.ts` / `kitHtml.ts` / `kitDeckStyles.ts`** — new optional `definitions: { term, meaning }[]` on a teach slide, rendered as a **Definitions row directly under Key points in the click-to-zoom diagram view**; slides that carry one get `.kdiagram--hasdefs`, which is the only thing that shortens the diagram, so every existing zoomed diagram keeps the exact size it had. **`backend/src/scripts/renderKitPreview.ts` (new)** — renders any week/day deck to a standalone HTML file with no DB and no server.
