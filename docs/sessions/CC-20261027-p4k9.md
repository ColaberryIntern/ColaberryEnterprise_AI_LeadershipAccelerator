## Goal

Build the gov contract **Vet → Build → Assign** funnel Ali asked for: a daily first-round
sweep that eliminates (hides) or promotes candidates to Round 2 (ZIP upload), a Round-2 lane
that advances or hides, and a Round-3 "ready to assign" lane with one-button approve + pick-intern.
Hidden/eliminated items drop into a collapsed "Passed on" drawer.

Key design decision (grounded in the backend/frontend maps): the three stages are **derivable
from existing state** — no schema change, no migration. Stage 1 eliminations already live in
`gov_opportunity_dismissals` (keyed on discovery uuid, already filtered from the feed); Stage-2
eliminations are the `no_bid` decision; stage is a pure function of `decision` +
`delivery_project_id` + whether the build is materialized.

## Plan (two phases, one PR each)

- **PR 1 (backend):** a read-only pipeline-projection endpoint + pure stage module + unit tests.
- **PR 2 (frontend):** the 3-lane board page + nav + Passed-on drawer + screenshot review.
