## Design decision (why no migration)
A feed row joins to its `gov_qualifications` record by `canonical = 'gws:' + uuid` — the exact key the
"Qualify" action writes. That record's `decision` + advisory `requirements_json.approval` already express
the approval ladder, so the page badge derives from one source of truth and can never drift.
