## What this ships

Read-only. Twelve GETs behind an admin guard, no write path, no send, no flag touched.
§27's seven write routes are Phase B, where a human sees the consequence as they flip it.

| Surface | What it answers |
|---|---|
| Overview | 153 decisions on the latest run: 11 waited, 142 actionable, 130 with content, 12 gaps |
| Journey | The roster by state and overlay, with scores, filtered and paginated |
| Decisions | Today's decisions, filterable, each row linking to its Why |
| Why | The winner **and every loser with its reason** — 142 of 153 have suppressed candidates |
| Shadow | What would have gone out: 130 emails + 12 lesson recommendations, 0 executed |
| Content | 646 assets / 552 active, coverage per purpose, and the gaps with their reasons |

## The three defects the verification loop caught before deploy

1. **A binding bug that would have 500'd the Content tab** — every test passed, because they
   all asserted on the SQL template and none on the bound value.
2. **A missing `try`/`catch` that would have restarted the backend container** on any query
   rejection across twelve routes.
3. **242 lines of service with no test at all.**

All three were mine, all three passed my own checks first, and none would have been visible
from a green suite.
