## A toolchain trap worth recording

The first typecheck of this branch reported **267 errors, all in `@types/*`**, and a deliberately
planted type error was invisible in that noise. Cause: `node_modules` junctioned in from a
checkout 5,855 commits behind main, supplying TypeScript 4.9.5 where backend requires ^5.7.3.
After a real `npm ci` the root still resolves 4.9.5 (hoisted from the frontend) and the correct
5.9.3 sits at `backend/node_modules`. The usable invocation is
`backend/node_modules/typescript/bin/tsc`. A clean typecheck from the wrong compiler is not a
clean typecheck, which is why the planted control error comes first.
