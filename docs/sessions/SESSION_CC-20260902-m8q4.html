Every signal said the deploy worked: container running, file on disk correct, CI green, exit code 0. Only fetching the public URL disagreed. Page HTML is never edge-cached (`cf-cache-status: DYNAMIC`), so fresh HTML pointing at a never-before-seen URL is guaranteed to miss the cache. The subtle part is the chain — `index.html` → `site.css` → `design/colors.css`: if a token file changes and the stylesheet's URL does not move, the stale CSS is still served while everything looks correct. That case is the third test. Applies to all three apps rather than this one, because the failure is a property of the build, not of a brand.
