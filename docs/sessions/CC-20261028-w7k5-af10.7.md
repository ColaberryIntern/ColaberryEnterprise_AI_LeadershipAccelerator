    repository". Caught by the plan audit, not by me.

    the plain-JS scripts "run from source inside the container". The image has **`/app/dist` and

    the image** — `find /app -name agentRoster.js` returns nothing. They are `docker cp`'d in and
    run from `/tmp`, which is what `attachArtifactToTicket.js` documents. Two plan-audit cycles
    accepted the original wording before executing disproved it.
