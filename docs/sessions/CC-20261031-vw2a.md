## Root cause
The campus room links in `HqInside.tsx:85` and `HqPanel.tsx:55` were hardcoded `target="_blank"` for
EVERY open room — including the member's OWN office (cockpit) room shipped in #3508. The "view as"
read-only token lives in `sessionStorage`, which is per-tab, so opening the cockpit in a NEW tab carries
the admin's own token instead of the impersonated member's → `requireGovProjectAccess` sees a non-member
→ 404. (The room id itself was correct — it's the delivery project id the route expects.)
